# Epi-Pilot AI

**硬膜外穿刺の抵抗消失（LOR）をAIが判定し、1軸ロボットが針を自動停止するシミュレーション**
Physical AI 応用1 最終課題

> ⚠️ 教育用のシミュレーションです。実在の患者・実測データ・医療機器は一切使用していません。
> 数値はすべて合成データ上のもので、臨床性能を示すものではありません。実機のアクチュエータに接続しないでください。

## 概要

硬膜外麻酔では、術者が左手でTuohy針を進め（黄色靱帯では線維を切るような「プツプツ」という手応え）、
右手親指で生理食塩水を入れたガラスシリンジを一定の圧で押し続けます。針先が硬膜外腔に入ると抵抗が消えて液が入ります（抵抗消失, LOR）。

本作品では、この2つの感覚を2つのセンサー信号に置き換えました。

| 術者の感覚 | ロボットの入力 |
|---|---|
| 左手：針を進める抵抗・プツプツ | 信号① 針の前進抵抗（直動アクチュエータの力） |
| 右手親指：シリンジの抵抗消失 | 信号② シリンジ内圧＋プランジャーの移動 |

AI（RandomForest、10 Hz）が針先の状態を「組織内／黄色靱帯／硬膜外腔」の3つに判定し、ロボットは
**前進（2.0 mm/s）→ 黄色靱帯を検知したら減速（0.6 mm/s）→ 硬膜外腔と判定したら停止** と行動を変えます。
AIは針先の深さ・位置の情報を使いません。

## 結果（学習に使っていない仮想患者100人）

| | Epi-Pilot AI | 従来の圧閾値法 |
|---|---|---|
| 成功（硬膜外腔で停止） | 100人 | 77人 |
| 早期停止 | 0人 | 3人 |
| 硬膜に到達（硬膜穿刺に相当） | 0人 | 20人 |

詳細は `output/result_summary.json` と `output/results_100_patients.csv` を参照してください。

## 実行方法

Python 3.10 以降。

```bash
python3 -m pip install -r requirements.txt
python3 epi_pilot.py --test      # 学習・100人評価・ログ出力（数分）
python3 epi_pilot.py --render    # 上記＋動画・図の生成（さらに数分）
```

`ffmpeg` がない場合は `requirements.txt` の `imageio-ffmpeg` が使われます。
日本語フォントは Mac（ヒラギノ）、Windows（游ゴシック・メイリオ）、Linux（Noto Sans CJK）を自動で探します。

## 仮想患者のモデル（シミュレーション上の設定）

以下はAIの判定を試すために設定した条件であり、臨床での頻度や実測値に基づくものではありません。

- 穿刺経路の層構造：表皮・真皮 → 皮下組織 → 棘上靱帯 → 棘間靱帯（上下の棘突起の間）→ 黄色靱帯 → 硬膜外腔 → 硬膜 → くも膜 → くも膜下腔 → 脊髄（馬尾）
- 各層の厚さに個体差を設定（例：皮下組織 8〜32 mm、黄色靱帯 3〜6 mm、硬膜外腔 3〜7 mm）
- 黄色靱帯通過時の抵抗変動（線維性の断続的抵抗）の頻度・振幅に個体差を設定
- 評価条件として、抵抗消失の程度が小さい例（仮想患者の約25%）を設定
- 評価条件として、棘間靱帯内で一過性の圧低下が生じる例（偽の抵抗消失、同約60%）を設定
- 臨床手技に準じ、LORシリンジは針先が棘間靱帯内に固定された後に接続する

**評価条件の割合についての但し書き**
抵抗消失が弱い例（約25%）と偽の抵抗消失（約60%）の割合は、臨床で想定される頻度より意図的に高く設定しています。
まれでも判定を誤ると危険な場面を十分な数含めることで、AIが誤って止まったり止まり損ねたりしないかを重点的に検証するためです（ストレステスト）。
一方、偽の抵抗消失が多いと、従来の圧閾値法は早期停止を避けるために閾値を低く設定せざるを得ず、弱い抵抗消失を見逃しやすくなります。
したがって、本評価での両者の差（成功 100人 対 77人）は、この設定によって大きく表れている可能性があり、臨床に近い頻度では差が小さくなることが考えられます。

## 省略した臨床上の要素

針の刺入角度と3次元的な方向修正、骨（棘突起・椎弓）への接触と刺し直し、逆血（血管内迷入）や髄液逆流の確認、
患者の体動・呼吸、テストドーズなどは扱っていません。
